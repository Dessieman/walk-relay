    Settings & help

    How it works: just play. When the host closes Big Walk, the journey uploads, and everyone else's copy updates within about a minute, so anyone can host next time. Saves are never touched while Big Walk is open.

    Avoid: two people hosting the same journey at the same time. Walk Relay warns you, and if it happens anyway, it keeps both versions.
